Classification is **TOKEN-BASED** (split tool name on `.`/`_`/`-`, whole-token match): **danger checked FIRST**, A0 only via a **positive safe-verb allowlist**, everything else (unknown / benign-token-in-dangerous-word / dangerous-target) → **fail-closed A3**. Action record `{seq,ts,agent,tool,args_hash,tier,decision,approver,result_hash,cert_digest,prev_hash,entry_hash,sig}`, Ed25519-signed + chained; **ts IS in the digest** (tamper-evident); a **separately-signed HEAD** {count,last_seq,head_hash,sig} anchors LENGTH so tail-truncation/wipe are caught (not just middle-delete).
