Turns CRUCIBLE from a scanner that COLLECTS into an engine that REASONS OVER intelligence. Designed by an 8-agent grounded workflow. **One-substrate principle:** every intel datum is an `Observation`; nothing enters the graph except by PROJECTING an Observation; the world-model's existing Beta-belief upsert (`worldmodel/graph.py:_seed_belief`/`_update_belief`) IS the fusion engine. Reuses belief/provenance/pathfinding/VOI(`goal_tree.expected_information_gain`)/kernel — never duplicates. On branch **ops-console** (committed be2c97d, after the console work).

**Locked scope:** Phase A = reasoning core (done); egress = both (offline ingest + gated live collectors, Phase B); new `intel/` package; predictions = labeled hypotheses, gated (never auto-scanned). Oracle/`verify` stays the FINAL authority — intel decides WHERE to spend effort.

**KEY DISTINCTION:** `Observation` ("what is true" → world-model node/edge with Beta belief) vs `Evidence` ("what bears on THIS claim's truth" → likelihood-ratio ledger on a `ScientificHypothesis`). Adapter = `intel.project.observation_to_evidence`. The Scientific Confidence Engine is a STANDALONE sibling `confidence/` package (reused beyond intel), NOT under intel/.

**Phase A files (all offline, stdlib+pydantic):**
- `worldmodel/models.py` EXTENDED: NodeKind += DOMAIN/CERTIFICATE/ASN/NETBLOCK/ORGANIZATION/IDENTITY/APPLICATION; EdgeKind += RESOLVES_TO/PRESENTS_CERT/ANNOUNCES/HOSTS/RUNS/OBSERVED_ON/ASSET_OWNS/SAME_AS. **HARD RULE: never reuse `EdgeKind.OWNS` for ownership** (attacker-state postcondition; a derivation rule would hallucinate attacker reachability) — use `ASSET_OWNS`. Enum widening only, schema/round-trip unchanged.
- `confidence/{models,engine}.py` — SCE. `Evidence`(likelihood_ratio×weight×independence → effective_woe), `ScientificHypothesis`(prior + alternatives + residual_prior, MECE; from_kernel_hypothesis), `assess()` = log-odds accumulation → softmax over {focal, alts, residual} → Beta CI (reuses `_belief_sd`) → value-of-next-evidence (reuses EIG). 13 tests.
- `intel/refs.py` — `EntityRef`(frozen, kind:NodeKind+key, `node_id`==worldmodel node id, asset/owner tier), `canonicalize()` (idna domain, canonical CIDR, AS<n>, sha256 cert).
- `intel/models.py` — `Observation` (obs_id/source/subject:EntityRef/relation:EdgeKind|None/object/Admiralty `SourceReliability` A-F×1-6 → weight()/`Polarity` affirms|refutes/seq/`truth_confidence()`/`claim_key`).
- `intel/fuse.py` — `fuse_observations` batch noisy-OR: dedupe-per-source, drop reliability≈0, `alpha=1+W·C, beta=1+W·R`. Saturates without runaway; contested→0.5; worthless→Beta(1,1) unknown.
- `intel/project.py` — **KEYSTONE `project_observation(world, obs, seq)`**: c_eff=0.5+r·(t−0.5); add_node/add_edge(confidence=c_eff) → belief accrues FREE. Belief RISES on corroboration, FALLS on refutation (max-confidence can't). Order-independent (Beta commutative). `project_fused` (Path B), `observation_to_evidence` (→ SCE).
- `intel/{signals,resolve}.py` — entity resolution. Signals fanout-DISCOUNTED (a cert on 500 hosts is weak) → this is the anti-catastrophe rule. resolve(): seed named assets (domains); merge on ≥MERGE_THRESHOLD_BITS(4.0) LLR via union-find; attach DEDICATED artifacts (cert/host whose presenters/resolvers are all in one cluster); owner-tier (ASN/netblock via ANNOUNCES + IP containment) → `ASSET_OWNS`, NEVER merges. Entity.confidence = bottleneck of merge tree; every merge cites its SignalHit (explain()). Golden = worked example (api+backend+10.15.4.2+certXYZ → one asset owned by AS64501). 18 tests.
