Voice is just another INTERFACE onto the one authorized KERNEL path — recognized text crosses the same T0 router + WARDEN gate + signed action log (proven: a voice request logged as `cascade.answer.t1 A0 auto` in the WARDEN spine).

**Modules:** `pipeline.py` = the frame-driven, full-duplex **state machine** IDLE→LISTENING→THINKING→SPEAKING with **barge-in** (during SPEAKING, VAD speech OVER the TTS cancels it mid-utterance → re-LISTEN); `components.py` = small Protocols (Vad/WakeWord/Asr/Tts/AudioSink/Dispatch) + deterministic MOCKS; `backends.py` = ZERO-dep real backends (`EnergyVad` RMS, `EnergyWake` speech-onset stand-in, `FileAudioSource`/`FileSink` stdlib-wave, `SilenceTts` fallback) + LAZY optional ML (`WhisperAsr` faster-whisper, `SileroVad`, `OpenWakeWord`, `PiperTts`, `MicAudioSource`, `SpeakerSink`); `dispatch.py` = `KernelDispatch` (shells `sigil-kernel ask`, strips [T0]/[WARDEN] lines); `run.py` = `run_file`(WAV→WAV, zero hardware) + `run_mic`(live). CLI: `sigil voice --file <wav> [--out] [--asr auto|stub]` / `--mic [--wake energy|oww]`.
