SIGIL spine **retain-all SEGMENT ROTATION** — **MERGED to `thuram-nana/sigil` main @ 9885c6b (PR #14)**. Bounds the append-only, hash-chained, Ed25519-signed spine (was 93MB/43k records + growing; 23 of 34 consumers full-scan it) WITHOUT weakening tamper-evidence or append-only. Builds on the production-hardening tiers ([[sigil-production-hardening]]). 400 pytest (+ a crash-fuzz suite) + 26 Rust green; ruff+mypy clean.

**Design via two multi-agent workflows** (the explore+design phases, deeper than fresh agents): a **10-agent UNDERSTAND** (19 invariants, all 34 consumers mapped, prune-vs-rollback tamper conflict, durability/cutover contract, critique C1/C2) → a **17-agent DESIGN PANEL** (4 competing designs, 12 perspective-diverse judges, synthesizer). Winner = **retain-all** because it keeps `entry_count` ABSOLUTE + the chain GENESIS-ROOTED, so `verify_chain`/`classify_head`/the signed head are reused BYTE-IDENTICAL and **C1 (durable external anti-rollback floor)/C2 (Merkle commitment)/state-folding/head-migration DO NOT ARISE** — a cold verifier judges a rotated store identically to today's.

**Owner scope decisions:** retain-all ONLY (NO hard-prune); ship CAPABILITY ONLY (the real 93MB spine is NEVER touched — migration is the explicit one-way `sigil spine migrate`).

**Review caught real defects at EVERY slice** (the discipline paid off): live-appender-resurrects-spine.jsonl FORK (reconciler must run on the append path too, not just __init__); layout cross-store contamination (stem namespacing); kill-switch UN-HALT after migrate (change_token, an A4 fix pulled forward); manifest path-escape; get()/append/seam FAIL-OPEN vs the fail-closed reads; an env-armed `os._exit` shipped in the append path (→ test-installed hook); a NEGATIVE-threshold seal-every-append self-DoS (→ clamp); a `tail()` NON-CONTIGUOUS window under concurrent compaction = a **replay-dedup BYPASS on the device-arm path** (tail feeds arm_by_device — tail needed the same retry + `_read_segment_tail` must RAISE not return [] on a vanished segment); two concurrent compactors crashing on a shared temp (→ unique mkstemp); a buggy+non-load-bearing reader-grace (os.replace preserves mtime → zero grace; readers are actually protected by open-fd+retry → DROPPED the trash/reaper, unlink directly for immediate reclaim).

**LESSONS:** (a) the design's own judge flagged the S0 migration crash-window as a fatal flaw BEFORE I built it — reading the synthesized spec's fatal_flaws is worth it. (b) A fix can close only HALF a window (S0 read-fallback closed post-manifest but not pre-manifest) — the re-check caught it. (c) Test-only fault injection must NOT read an ambient env var in production (footgun) — install a hook from the test. (d) "byte-identical" claims are data-file-only; a lockfile/artifact appearing is a real deviation. (e) an advertised safety mechanism (reader-grace) can be BOTH buggy AND non-load-bearing — the reviewers proved the retry net (not the trash) protects readers, so the honest fix was to DELETE the trash. Foundational-file edits (store.py) stay orchestrator-owned (sequential), review fans out in parallel. gh=thuram-nana.
