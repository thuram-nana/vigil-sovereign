THE SYSTEM

One provable system, end to end

VIGIL fuses an LLM-driven offense engine (redamon-shaped) and a Go-shaped orchestration body onto one deterministic sovereign core: the LLM, its tools, the knowledge-graph, and the cognition governors only propose — nothing they say is true until a deterministic CRUCIBLE oracle re-executes the evidence and mints a signed FACT, nothing acts until the conjunctive gate (CRUCIBLE authority ∧ WARDEN tier ∧ m-of-n destruction) authorizes it, and nothing leaves the box until the egress gate lets it out — pinned to loopback for this validation build. Every one of those decisions, and every use of the system itself, lands as an append-only, Ed25519-signed, hash-chained record on one spine, witnessed and offline-verifiable forever.

The same invariant runs through every layer below: L1 is the core substrate that enforces it, L2 is the per-turn loop that exercises it, L3 is the offense “body” bolted onto it, L4 is the live backends that make it real against a loopback target, L5 is its defensive mirror (the AEGIS Detection Mirror proving the same attacks from telemetry), L6 is the auto-patch loop that may act only on a FACT, and L7 names the veracity firewall and trust boundaries that hold across all six.

L1 — THE SOVEREIGN CORE

VIGIL L1 — The Sovereign Core: propose → attest → gate → egress → oracle → sign → spine

L1 is the deterministic center every offense action routes through. The LLM/tools/graph/critic only PROPOSE: a raw model response is parsed fail-closed into a non-authoritative LLMDecision (agent/react.py). Before any gated action the always-on usage-attestation LEDGER mints a signed WHO/WHEN/WHAT record and fail-closed DENIES if it cannot (attestation/). Every target-touching edge then crosses the CONJUNCTIVE GATE — CRUCIBLE authority (killswitch/scope/window/budget) ∧ WARDEN tier A0–A3 (phase→tier, raise-only floor) ∧ (for destructive/high-blast) an owner-inclusive m-of-n threshold-destruction authorization — first-failure-wins, any error is a DENY. Only an ALLOW reaches the EGRESS gate (gateway/denylist.py), which hard-denies metadata/loopback/private/non-global egress and lets traffic out only to charter-authorized IPs (live-fire validation is pinned to loopback). A tool's raw output is taken in honestly: LLM claims become LEADs; an exploit_succeeded claim re-fires the deterministic CRUCIBLE ORACLE over the retained context, and ONLY an oracle confirmation on a known bug-class mints a signed, proof-carrying EvidenceCertificate (m-of-n) — a FACT. Facts carry a signed evidence_ref enforced at the type level (agent/state.py); the veracity path is demote-only (unconfirmed → labelled lead, never up). A FACT crosses the two-env boundary as INERT signed JSON DATA only (inert_finding.py; keyless offense worker), is re-verified m-of-n on the sovereign side, and appended to the one append-only Ed25519 signed hash-chain SPINE (vigil_core: crypto/chain/canonical/models), anchored by a monotonic anti-rollback SignedChainHead. On top of the head sit the I2 witnessed transparency log (split-view-resistant under strict majority) and offline-verifiable SCITT/OpenVEX certs with RFC-6962 Merkle inclusion proofs. Every record — findings and attestations alike — is a domain-separated, canonical-JSON, Ed25519-signed link on an append-only chain.
