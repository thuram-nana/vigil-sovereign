About this score

This implements the public FIRST.org CVSS v3.1 base-metric equations, re-derived from the specification. Base metrics describe the intrinsic qualities of a vulnerability; temporal and environmental metrics (which adjust for exploit maturity and your own environment) are not included in this base calculator.

VIGIL carries the CVSS vector as a first-class field on every finding, but a severity number is never a verdict on its own — a finding becomes a FACT only when a deterministic oracle proves it exploitable. See how the proof works →
