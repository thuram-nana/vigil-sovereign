How can we help?

VIGIL is self-hosted, so most answers live in the product and the docs that ship with it. Here's how to reach a human and resolve the common things.

Request access or a walkthrough

Want to run VIGIL or see a finding prove itself? Email us and we'll set you up.

Email the team

Report a security issue in VIGIL

Coordinated disclosure with safe harbour for good-faith research: a 3-day acknowledgement and a 90-day window. Email thuram@thuramnana.com or open a private advisory on our repository. Please don't file security reports in public issues.

Common questions

Where is the documentation?

The full operator manual ships inside the product — open it from the cockpit. Deployment and bring-up guides live with the source you run.

Is my data sent anywhere?

No. VIGIL runs on your hardware and talks only to the LLM backend you configure (which can be a local model). There's no telemetry and no auto-update. See the trust center →

How do I erase an engagement's data?

Evidence is erased by cryptographic shredding — the keys that decrypt it are destroyed, so the data is unrecoverable. It's an operator action on your own deployment.

Self-hosted vs. hosted — which am I using?

The default is sovereign and self-hosted: your keys, your machine. A hosted offering is in development; until it ships, account/billing questions below apply only where you've explicitly enabled them.

Billing & account recovery

Where the hosted billing surface is enabled, manage plans from your account area; password recovery is a single-use emailed link that also signs you out everywhere. These apply only to the hosted mode.

We don't run a public chat widget or ticket queue — email reaches a real person, and security reports are triaged first.
