Proof

Zero FP

Zero false positives by construction

No deterministic oracle fires, no FACT is minted — the model is never trusted for a verdict. Unproven observations are labelled LEAD, never dressed up as confirmed.

Sovereign

Run it on your own hardware with your own model keys (Ollama, vLLM, Bedrock, Vertex, Azure, Mistral). The owner holds the only signing keys. A deployment tier is not, by itself, a network control — pair it with your firewall.

Offense + Defense

Honest
